# 03 — Non-Functional Requirements

Targets marked *(target)* are initial goals to be measured in Phase 15; they are not claims.

| ID | Category | Requirement |
|---|---|---|
| NFR-01 | Performance | Imports of ≥1M rows run in background; API never blocks. Import throughput measured and documented *(target ≥ 20k rows/s via bulk COPY path — measured ~12k rows/s at 1M rows, see doc 06; target not met)*. |
| NFR-02 | Performance | Transaction list/search p95 < 500 ms on 1M+ rows with indexes *(target)*; keyset pagination for deep pages. |
| NFR-03 | Performance | Single-transaction inference latency measured per model and reported (Detection Latency metric). Batch throughput measured (Throughput metric). |
| NFR-04 | Scalability | Modular monolith; Celery workers horizontally scalable; Neo4j projection loadable from a subset when full graph is too large. |
| NFR-05 | Reliability | Idempotent tasks; import jobs resumable/restartable from last committed chunk; failed tasks surface error state. |
| NFR-06 | Consistency | PostgreSQL authoritative; Neo4j sync is one-way, idempotent, watermark-tracked, rebuildable (see doc 05). |
| NFR-07 | Reproducibility | Training takes seed, dataset hash, split definition, library versions; artifacts hashed; experiments re-runnable by CLI. |
| NFR-08 | Security | See [10-SECURITY-AND-RBAC.md](10-SECURITY-AND-RBAC.md). Backend enforces every permission. |
| NFR-09 | Privacy | Only public/synthetic/anonymised data; account identifiers masked in UI for roles without need (configurable). |
| NFR-10 | Auditability | Append-only audit log for auth, data changes, case actions, config changes, exports. |
| NFR-11 | Maintainability | Service-layer pattern; no circular app dependencies (enforced by import-linter in CI); type hints; ruff + mypy (backend), ESLint + `tsc --strict` (frontend). |
| NFR-12 | Testability | Backend pytest-django, frontend Vitest + Testing Library, E2E Playwright; coverage reported (goal ≥ 80% on services/domain). |
| NFR-13 | Usability/Accessibility | Keyboard navigable, semantic HTML, WCAG 2.1 AA colour contrast target; responsive ≥ 360 px. |
| NFR-14 | Observability | Structured JSON logs, request IDs, Celery task logging, health/readiness endpoints. |
| NFR-15 | Portability | `docker compose up` runs the full stack; dev/prod settings separated; no secrets in repo. |
| NFR-16 | Documentation | Docs updated in the same change as code (Part 7 rules). OpenAPI generated by drf-spectacular. |
| NFR-17 | Data retention | Configurable retention/deletion policy documented and implemented for uploads/evidence; backup/restore procedure documented and tested. |
| NFR-18 | Compatibility | Pinned runtime: Python 3.12 (container), Node 22 LTS (container), PostgreSQL 16, Redis 7, Neo4j 5 Community. See D-002. |
